# Valevo Bot — безопасная установка на клубный ПК

## Главное
Архив НЕ содержит `valevo.db`, чтобы случайно не затереть рабочую базу клуба.
Перед обновлением сделайте копию рабочей базы.

## Установка
1. Остановить старого бота.
2. Скопировать папку проекта на клубный ПК.
3. Перенести рабочий `valevo.db` в корень проекта, если его там нет.
4. Проверить `.env`:
   - `BOT_TOKEN`
   - `ADMIN_IDS`
   - `YCLIENTS_COMPANY_ID`
   - `YCLIENTS_PARTNER_TOKEN`
   - `YCLIENTS_USER_TOKEN`
   - `YCLIENTS_LOYALTY_CARD_TYPE_ID=115374`
   - `YCLIENTS_BONUS_RUB_PER_HOUR=1000`
   - `YCLIENTS_ISSUE_CASHBACK=1`
   - `YCLIENTS_AUTO_SYNC=1`
   - `YCLIENTS_AUTO_CREATE_LOYALTY_CARDS=1`
5. Установить зависимости:
   ```powershell
   pip install -r requirements.txt
   ```
6. Запустить миграции/инициализацию:
   ```powershell
   python scripts/safe_update_db.py
   ```
7. Запустить бота:
   ```powershell
   python main.py
   ```

## Что автоматизировано
- ручная кнопка синхронизации с YCLIENTS убрана;
- при регистрации бот сам ищет клиента по телефону и привязывает `yclients_client_id`;
- при старте бот сам проходит по всем пилотам и синхронизирует YCLIENTS;
- бот сам проверяет карту `Valevo Bonus`;
- если API YCLIENTS разрешит выпуск карты — бот попробует выдать карту сам;
- если API не даст создать карту — операция не теряется, а попадает в очередь `pending_yclients_operations`;
- начисления бонусов через админку тоже идут через очередь, если карта пока недоступна;
- сезонные бонусы сгорают через 30 дней;
- бонусы `referral`/`admin_manual` не сгорают автоматически.

## Сезонные суммы
- 1 место: 20 ч × 1000 = 20000 ₽
- 2 место: 10 ч × 1000 = 10000 ₽
- 3 место: 5 ч × 1000 = 5000 ₽

## Если YCLIENTS завтра недоступен
Бот всё равно запускается, профиль/leaderboard/админка работают.
Операции YCLIENTS кладутся в очередь и повторяются фоном.
