# VALEVO — объединённая Linux-сборка

## Что вошло

- Новая турнирная система v3 стала основной: базы 100/110/120/130, множители TOP-7 2.0…1.4, бонусы пар GT500+F4/ALL = +20 и DTM+Touge = +30, квалификация по эталону.
- Миграция текущей SQLite запускается автоматически один раз, перед изменениями делает SQLite backup и включает турнирные уведомления всем пилотам.
- Рейтинг в Telegram: общий TOP-7 с баллами + блок каждой дисциплины с лучшими временами; без пояснения формулы.
- TOP-5 уведомления отслеживаются по общему рейтингу и каждой дисциплине, с debounce/quiet-hours/лимитами.
- Разделены роли: ADMIN_IDS — только «Установить время»; SUPER_ADMIN_IDS — вся административная панель и административные callback/FSM.
- Супер-админ может менять номер пилота и телефон.
- Реферальная программа: `t.me/<bot>?start=ref_<telegram_id>`; новый уникальный пользователь после регистрации создаёт реферал, обоим начисляется по 350 ₽ Valevo Bonus, повторное начисление блокируется БД.
- Telegram Mini App встроен в проект и использует тот же BOT_TOKEN/initData и ту же SQLite. Есть рейтинг, профиль, рефералы и рулетка Valevo Bonus.
- Рулетка сохранена: спин 1000 ₽ Valevo Bonus, 20 призов, списание fail-closed, бонусный приз при временной ошибке YCLIENTS ставится в очередь.
- Linux: отдельные контейнеры `valevo-bot` и `valevo-webapp`, общие data/logs/backups, nginx example, HTTPS-ready.
- `tv_board.py` не менялся относительно присланной рабочей сборки.

## База и первый запуск

Docker ожидает текущую БД в `data/valevo.db`. В архиве находится копия БД из присланной рабочей сборки. При первом старте `init_db()` добавит новые таблицы/колонки, затем `apply_tournament_update()` сделает backup и применит турнирную миграцию.

## Роли

- `ADMIN_IDS=...` — только установка результата/времени.
- `SUPER_ADMIN_IDS=...` — пилоты, телефон/номер, трассы, удаление времени, очистка, Week CUP, эталоны, рассылка, административные действия бронирований/поддержки.

## Mini App

Задайте публичный HTTPS URL в `WEBAPP_URL`. Кнопка `🚀 Открыть VALEVO` появится в главном меню бота только когда URL заполнен.
