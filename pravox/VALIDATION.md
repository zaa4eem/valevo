# Проверка правоХ с локальным тестовым ИИ

Дата: 6 сентября 2026 года.

## Локальный результат

57 автоматических тестов проходят. Проверены подпись и срок Telegram initData, права администратора и владельца диалога, три бесплатных запроса, проверка подписки и отказ при недоступности Telegram, общий контекст чата и Mini App, идемпотентность и конкурентные запросы, обработка ошибок ИИ, допустимые источники, статистика, CSV, удаление истории и резервное копирование SQLite.

Добавлены проверки локального адаптера: работа без ключа, обязательная маркировка, отсутствие фиктивных источников, ограничение контекста, отклонение незавершённых/некорректных ответов и внешних адресов Ollama.

Отдельные проверки покрывают размещение в /pravoXru/: HTML, ресурсы, API, Origin, healthcheck и адрес меню Telegram. Проверки синтаксиса Python, JavaScript и shell проходят. Compose разобран как YAML; веб-порт привязан к loopback, сервисы приложения работают с read_only.

## Что не проверено в реальной среде

- SSH: соединение с 222.167.211.74:22 недоступно из среды разработки (Network is unreachable). Пароль не проверялся.
- Telegram: прямой доступ к API недоступен из среды разработки. Токен и права бота в канале не проверялись.
- ИИ: добавлен локальный Qwen3 4B без API-ключа. Модель не скачивалась и не запускалась в этой среде. Тесты используют подставные ответы; качество юридических ответов реальной модели не оценивалось.
- Docker отсутствует в среде разработки. Контейнеры не собирались и не запускались.
- Браузерная проверка и проверка внутри Telegram на устройствах не проводились.
- Конфигурация действующего сайта не читалась и не менялась. HTTPS-маршрут не опубликован.

## Развёртывание

Владелец подтвердил: zaa4eem.ru находится на сервере 222.167.211.74. Целевой адрес — https://zaa4eem.ru/pravoXru/. Подготовлен фрагмент для существующего Nginx; применять его следует после проверки используемого веб-сервера. Пошаговая установка и проверки после запуска находятся в README.md.

В архиве нет рабочих ключей, пароля сервера, пользовательских данных или заполненного файла окружения. Подготовка к установке завершена; фактический запуск остаётся невыполненным.

Повторная попытка подключения 6 сентября: SSH — Network is unreachable, Telegram API — ошибка DNS. Сетевые ограничения не обходились. Доступная площадка Sites работает в Workers с 128 МБ на изолят: она не подходит для размещения выбранной локальной модели и не использовалась как сетевой посредник.
